Windows build of Pynsource — 64-bit, Python 3.13, wxPython 4.3.2.

## Install

Download `pynsource-win-<tag>-setup.exe` below and run it. It installs to
`C:\Program Files\Pynsource`, adds a Start Menu entry, and can be removed again
from *Apps & features*.

## Installation tips (first run)

Windows SmartScreen warns about the installer, because it is unsigned (no paid
code-signing certificate):

1. The blue **"Windows protected your PC"** box appears — click **More info**.
2. Click **Run anyway**.
3. The installer then runs normally; no further prompts.

## Notes

- 64-bit Windows only (Windows 10 and 11).
- Editing diagrams is free; the Pro features (zoom, drag-to-connect, module
  visualisation) need a licence — https://www.pynsource.com/pricing.html
